# LectureLoop 字幕翻译（Chrome 插件）

看网页视频（YouTube、Netflix、各种在线播放器）时，把正在显示的字幕**实时翻译**成你要的语言——**法语 / 英语 / 中文互译**。译文悬浮在视频画面上，可拖动、调字号和背景，全屏也能看。

它读取的是**网页里已经有的字幕**，不是听声音识别：所以视频本身要有字幕（官方字幕或自动字幕都行）。没有字幕的视频目前不支持（见“局限”）。

## 安装（开发者模式，2 分钟）

1. 拿到插件文件夹：LectureLoop 网页的 **设置 → Chrome 字幕翻译插件** 下载 zip 并解压；或者直接使用仓库里的 `lectureloop/extension/` 文件夹。
2. Chrome / Edge 地址栏打开 `chrome://extensions`，右上角打开**开发者模式**。
3. 点**加载已解压的扩展程序**，选择 `lectureloop-subtitles`（或 `extension`）文件夹。
4. （建议）点浏览器工具栏的拼图图标，把“字幕翻译”固定出来。

要求 Chrome / Edge 116 或更新版本。更新插件：覆盖文件夹后，在 `chrome://extensions` 点它的刷新按钮，再刷新视频页面。

## 使用

1. 打开视频，**先在播放器里打开字幕**（用哪种语言的字幕都行）。
2. 点工具栏的插件图标，打开开关（或按 **Alt+T**）。悬浮层会出现在视频画面上。
3. 在弹窗里选“字幕语言 → 翻译成”。字幕语言默认“自动判断”；如果整部剧都是同一种语言，指定它更准。
4. 勾选“以后打开 xxx 自动开启”，这个网站下次就不用再点。

### 字幕侧边栏（v0.2）

点弹窗里的 **📖 字幕侧边栏**（或按 **Alt+S**，或 Chrome 侧边栏菜单里选“LectureLoop 字幕翻译”）。侧边栏跟随当前标签页：

- **字幕**：识别到的**全部字幕**，原文 + 译文，当前句高亮并自动居中。点一句跳到那里播放；悬停有 ▶ 从这里播放、🔁 **循环这一句**、☆ 收藏。字幕轨道整条载入的视频会**一次性列出整部**；网站字幕（YouTube / Netflix 等）则边播边出现，第二遍起完整。顶部“翻译全部”可把没有译文的句子一次翻完。
- **收藏单词**：点字幕里的词 → 看**结合这句话的译文** → 标成 🔴不会 / 🟡模糊 / 🟢会了。之后所有字幕里这个词都按颜色显示（红、黄带波浪线），扫一眼就能看到生词。
- **收藏句子**：点 ☆ → 红 / 黄 / 绿 / 蓝（好句），整行带颜色。
- **单词**：这个视频里的词频表（可隐藏常见词），挑生词。
- **收藏**：所有视频里收藏的词和句子，可按类型、颜色筛选，▶ 跳转，**导出 TSV（可导入 Anki）**。

**不重复翻译**：看过的字幕和译文保存在本机。同一个视频再看一遍、循环播放、刷新页面，都直接用已有的，不再请求翻译服务；别的视频里出现同样的句子（“Merci.”“On y va !”）也直接命中。设置页可以看占用并一键清除（收藏不受影响）。之后如果填了 AI 密钥，之前看过的视频仍显示当时的译文，想重翻就在设置页清除。

悬浮层上鼠标悬停会出现小按钮：`A−` `A＋` 调字号，`原` 同时显示原文，`✕` 关闭。直接拖动字幕块可以换位置（会记住）。

**网站自带字幕和悬浮字幕重复了？** 弹窗里勾“隐藏网站自带字幕”，只看悬浮层（会同时带上原文）。

**怎么找到字幕的？** 依次尝试：

| 来源 | 说明 |
|---|---|
| 手动选取 | 网站没被识别时：点弹窗里的“**选取字幕位置**”，先暂停视频让字幕停在屏幕上，再点一下字幕文字。会记住这个网站。 |
| 已知网站 | YouTube、Netflix、Prime Video、哔哩哔哩的字幕层。⚠️ 这些选择器按它们公开的页面结构写成，网站改版会失效——失效时用“选取字幕位置”。 |
| 视频字幕轨道 | 标准的 `<track>` / WebVTT 字幕（很多播放器、课程网站、自建站都用）。如果整条轨道已经载入，会**提前翻译接下来约 90 秒**，播放到时译文已经就绪。 |

## 翻译引擎

- **Google 免费翻译**（默认，不需要密钥）：速度快、质量够看。是非官方的网页接口，用得太频繁可能被临时限流。
- **AI 密钥**（可选，设置页里粘贴）：自动识别 Anthropic Claude、OpenAI、Gemini、DeepSeek、Kimi、智谱、百炼、硅基流动、豆包、OpenRouter、Groq、xAI，或任意 OpenAI 兼容地址（比如本机 Ollama）。AI 会按上下文处理语气、俚语和玩笑，明显比机翻自然。字幕只用“快速模型”（延迟优先）。
- **Chrome 内置翻译**（本机模型，免费、离线）：较新的 Chrome 才有，语言包要先下载好。
- “自动”档：有 AI 密钥用 AI，失败或限流时**自动降级到 Google 免费翻译**，并在弹窗里说明原因；都不行就只显示原文，悬浮层右上角亮红点。

## 隐私与权限

- 安装时 Chrome 会提示“可以读取和更改所有网站的数据”：因为插件要在任意视频网站上读取字幕。**它默认休眠**——只有你在这个标签页点开关，或把这个网站设为“自动开启”后，才会读取字幕。
- 权限最小：`storage`（保存设置）、`sidePanel`（字幕侧边栏）、`unlimitedStorage`（保存字幕转录与翻译记忆，不被浏览器当作可清理数据）、`activeTab`（只在你点插件图标时，临时获得当前标签页的地址与访问权）、`scripting`（给**装插件之前就已打开**的页面补注入，免得你必须刷新）；另外只对列出的 AI 服务商域名、Google 翻译域名与本机地址有访问权限。
- 看过的字幕文字会保存在**这台电脑的浏览器里**（转录、翻译记忆、收藏），不上传、不共享，设置页可一键清除。
- 只有**字幕文字**会发给翻译服务（Google，或你选的 AI 服务商）。不读取、不上传页面其他内容，没有统计和日志。
- AI 密钥保存在这台电脑的浏览器里（`chrome.storage.local`），并设为仅插件自己的后台/设置页可读——网页和内容脚本读不到；密钥只会发给对应服务商。
- 代码不压缩不混淆（`dist/` 是 `src/` 打包后的可读文件），可以自己检查。

## 局限（诚实版）

- **没有字幕的视频不支持。** 听声音识别要另外的语音识别服务，还没做（计划见产品文档）。
- **没有在真实的 Netflix / YouTube / Prime / 哔哩哔哩上验证过**——开发环境访问不了这些网站。已知网站的适配是依据它们的页面结构，在仿制的页面上测试通过；真实网站如有出入，请用“选取字幕位置”，并把情况告诉我。
- YouTube **自动字幕**是一个词一个词往后“滚动”的，插件会等它停下来再翻译，所以译文比官方字幕慢一点。
- 用 AI 翻译时，网站 DOM 字幕（没有提前翻译）的译文会比原字幕晚约 1–2 秒；用 Google 免费翻译一般 < 0.5 秒。
- 侧边栏里，网站字幕（没有整条字幕轨道的站点）只能边播边记；YouTube 自动字幕的滚动文本可能出现少量重复句。
- 如果播放器把 `<video>` 元素本身设为全屏，悬浮层没法挂进去（浏览器规则）；大多数播放器全屏的是外层容器，不受影响。
- 只支持 Chromium 内核浏览器（Chrome / Edge / Brave…）。Firefox、Safari 不支持。

## 开发

```bash
cd lectureloop/app
npm install            # 只有 esbuild 与官方 SDK（插件本身不需要 SDK）
npm run build:ext      # 打包 src/ → dist/，生成 manifest.json 与 public/downloads/*.zip
npm test               # 含插件的纯逻辑测试，以及“构建产物没过期”检查
node tests/e2e/extension.cjs   # 真实 Chromium 加载插件的端到端测试（需 playwright + chromium）
```

- `src/core/`：`transcript.js` `recorder.js` `videokey.js` `words.js`（转录与单词，纯逻辑）、`tm.js` `store.js`（翻译记忆与 IndexedDB）、`sources.js`（字幕来源）、`translator.js`（队列/缓存/预翻译）、`overlay.js`（悬浮层）、`picker.js`（选取器）、`controller.js`（总控）、`engines.js` `llm.js` `keys.js`（翻译引擎与密钥，只在后台使用）。
- 提示词、服务商表、OpenAI 兼容客户端与网页版**共用**（`../app/public/js/lib/`），打包时直接引入。
- 改了源码后必须重新 `npm run build:ext` 并提交 `dist/` 与 zip；测试会检查它们是不是最新的。

## 1. 产品背景

### 1.1 问题陈述

留学生用非母语上专业课，承受的是**双重负荷**：

1. **听力负荷**：语速、口音、口头禅、插话、自我纠正；
2. **专业负荷**：术语密集、公式靠"口述"（"minus one"、"dot product of the normal vector with the feature vector"）。

现有工具（实时字幕、会议转录、AI 纪要）解决的是"**此刻看得懂**"，但留下四个缺口：

| 缺口 | 现象 | 后果 |
|---|---|---|
| **拐杖效应** | 字幕全程开着，眼睛读、耳朵闲置 | 课上看懂了，听力本身没有进步 |
| **转录即终点** | 文本沉在文件夹里，没有时间轴、没有音频绑定、没有练习机制 | 复习 = 重读，不是重听 |
| **卡点无处安放** | "刚才那句没听懂"只存在于当时的脑子里 | 最有训练价值的片段永远不会被回访 |
| **转录不可信** | 通用 ASR 在专业术语上系统出错 | 学生分不清"是我没听懂，还是转录错了" |

### 1.2 核心洞察

> **Transcript is the answer key; audio is the training material.**
> 转录文本是"标准答案"，课堂录音才是"训练材料"。

课堂是**免费、真实、与本人专业 100% 匹配、每周自动增长**的听力题库。LectureLoop 与普通实时字幕工具的本质区别：

|  | 普通实时字幕/转录工具 | **LectureLoop** |
|---|---|---|
| 终点 | 课上看懂 | **下次课需要更少的字幕** |
| 内容生命周期 | 一次性 | **长期复用（课程库）** |
| 字幕角色 | 目的 | **脚手架（可淡出）** |
| 听不懂的片段 | 被丢弃 | **被标记、被定向反复精听** |
| 转录错误 | 当作噪声 | **当作"听力陷阱"信号** |
| 成功指标 | 字幕准确率 | **卡点密度下降、盲听通过率上升** |

### 1.3 替代方案格局（基于公开信息的品类级概括，立项前需复核）

| 品类（代表） | 它们擅长 | 与本产品的差距 |
|---|---|---|
| 实时字幕/会议转录（Otter、Notta、Zoom 字幕、系统 Live Captions） | 低延迟字幕、会议纪要 | 无"课程→课时→片段"结构；无精听机制；无术语表；不围绕学习目标 |
| AI 听记/笔记（通义听悟、Notion AI 等） | 摘要、待办提取 | 摘要替代了"听"；缺少回听锚点与听力训练 |
| 视频语言学习（Language Reactor 等） | 双语字幕、逐句循环 | 面向影视/YouTube 内容，不面向"我自己的专业课" |
| 闪卡（Anki） | 间隔重复 | 制卡成本高；卡片是文字，不是"那一段声音" |
| macOS 语音备忘录 | 录音+转录，零门槛 | **本次样本来源**：转录无时间戳、术语错误多、无组织结构 |

**空白点**：没有产品把"课堂实时辅助"与"课后长期精听训练"打通成一个闭环。

### 1.4 样本研究：来自 2 份真实课堂转录

我们对用户提供的两份语音备忘录导出文件做了定量分析（词频/句长/口头禅为脚本统计；ASR 错误为人工结合上下文判断，完整清单见附录 A）。

| 指标 | 样本 A：Bioinfo & Omics | 样本 B：MLAI |
|---|---|---|
| 内容 | 决策树、随机森林、偏差-方差 | SVM、间隔、核函数 |
| 总词数 | 11,788 | 17,969 |
| 估算时长（150 词/分钟） | ≈ 79 分钟 | ≈ 120 分钟 |
| 段落结构 | 310 段（按停顿分段） | **1 段**（约 9.5 万字符无换行） |
| **时间戳** | **无** | **无** |
| 按标点切句 | 952 句，平均 12.4 词 | 2,056 句，平均 8.7 词（切得很碎） |
| 口头禅密度（okay + uh/um） | 555 次 ≈ 4.7 / 百词 | 442 次 ≈ 2.5 / 百词 |
| 高频口述公式词 | — | "minus" 66 次、"square" 41 次、"dot product" 7 次 |

**ASR 术语错误（人工识别，依据上下文推断，附录 A 有完整清单）**

| ASR 输出 | 实际应为 | 类型 |
|---|---|---|
| `decision treats` / `decision treatment` | decision trees | 近音 |
| `dog product`（×7） | dot product | 近音（/t/→/g/） |
| `linear reversion` / `logistic progression` | linear / logistic regression | 近音 |
| `super vector` | support vector | 弱读 |
| `Ginny's score` / `the genie entering` | Gini score / Gini impurity | 外来词（法语读音 /ʒini/） |
| `decision speed, which speaks attribute` | decision split, which tests an attribute | 近音 |
| `biased variance trade` | bias–variance trade-off | 近音/漏读 |
| `a kernel fashion` | a kernel function | 近音 |

**对产品设计的七条硬约束**

1. **无时间戳 → 必须"估算时间轴 + 绑定音频 + 锚点校准"**，否则谈不上精听。
2. **单段 9.5 万字符 → 自动断句 + 自动分 Part**；一节课 80–120 分钟不可能整段练，练习单元必须是"句 / 3–8 分钟片段"。
3. **术语错误集中在承载课程含义的核心概念，且多为近音/法语口音所致** → AI 纠错必须带"课程词表"；**纠错记录本身就是"听力陷阱"清单**（学生真正会听错的地方）。
4. **口头禅 2.5–4.7 次/百词** → 阅读视图可隐藏语气词，听力视图必须保留原样。
5. **公式靠口述** → 笔记要同时给"符号"与"口述"，并有"公式口述"标签。
6. **转录保留原始层** → `raw`（ASR 原文）与 `text`（纠正后）双层存储，纠错可撤销。
7. **校区在法国、讲者口音/语种混杂** → 语言选择在 Lesson 级；自动语种识别列入 P1。

| **P1 林同学（主）** | 中国籍硕士生，法国高校英语授课项目；专业课为 ML/生信/统计；讲者非英语母语 | 课上跟不上术语与公式口述；课后只能重读粗糙的转录 | 主 |

| **P3 Alex** | 在英美读研的中文母语学生 | 口音多样、课堂互动多 | 次 |
| 辅助角色 | 学习小组 / 语言辅导员 | 共享课程素材库（V2） | 暂缓 |

### 2.2 Jobs To Be Done

> 当我用外语上专业课时，我希望**课上不掉线**，而且**课后能把没听懂的地方变成针对性训练**，这样**下一次课我需要的字幕更少**。

### 2.3 场景时间线

| 阶段 | 用户行为 | 产品动作 |
|---|---|---|
| **课前** | 选择课程 / 语言；（可选）核对词表 | 加载课程术语表作为 ASR/翻译上下文 |
| **课中** | 开启实时字幕；一键标"没听懂"；字幕可淡出 | 字幕+翻译、同步录音、记录带时间戳的卡点 |
| **课后当天** | 一键归档；生成笔记；确认术语纠错 | 自动分 Part；摘要笔记；词汇/句式；听力陷阱 |
| **每日 15 分钟** | 做到期的卡点精听 | 盲听 → 听写 → 揭示 → 自评 → 间隔复习 |
| **考前** | 按标签（老师强调/公式口述）筛片段连续听 | 专题精听播放列表 |
| **课余看剧 / 看网页视频** | 看法语或英语的剧、纪录片、网课（YouTube / Netflix / 学校网课平台）；想跟着看又不想暂停查词 | 浏览器插件读取视频已有字幕，实时译成中文（或另一种语言），悬浮在画面上；可同时显示原文，字幕与译文互相对照 |

## 3. 产品目标与成功指标

### 3.1 目标

| 层级 | 目标 |
|---|---|
| **核心目标** | 让学生**反复精听课堂内容**，提升专业英语听力，而不只是翻译字幕 |
| 次级目标 | ① 课上降低跟不上的概率；② 课后沉淀可复用素材库；③ 把"没听懂"变成可管理的训练队列 |

| 类型 | 指标 | 定义 | MVP 目标（4 周自用验证） |
|---|---|---|---|
| **北极星** | **卡点密度下降率** | 每 10 分钟课堂的卡点标记数，第 4 周 vs 第 1 周 | ≥ 30% |
| 行为 | 周精听完成数 | 每周完成的卡点训练卡片数 | ≥ 40 / 周 |
| 行为 | 盲听通过率 | 首次盲听即自评"听懂"的比例 | 持续上升 |

| 性能 | 实时字幕延迟 | 语音到源语言字幕（P50） | < 1.5 s |
| 性能 | 翻译延迟 | 句子定稿到译文显示（P50） | < 2 s |

## 4. 产品原则

1. **复用优先于实时**：每一次实时听课，必须以"高质量归档"结束；归档质量是产品底线。
2. **字幕是脚手架**：所有字幕界面都提供"淡出/盲听"路径；练习默认盲听优先。
3. **轻标记，重练习**：课中标记是 1 次按键；富化（原因、标签、笔记）都推迟到课后。
4. **转录不可全信**：保留 ASR 原始层；纠错可见、可逆；纠错记录转化为训练内容。
5. **本地优先，隐私可控**：录音与文本默认只存在浏览器本地；仅在用户触发 AI 时发送文本片段（不发送音频）。
6. **降级可用**：没有 API 密钥、没有麦克风、没有音频文件时，核心流程仍能走通（离线摘要、文本朗读/静音计时器、演示课堂）。

## 6. 功能需求（MVP 优先）

### 6.0 核心数据模型（概览）

```
Course 课程 ──< Lesson 课时 ──< Part 片段（3–8 分钟，主题连贯）──< Cue 句级听力单元
                    │
                    ├── Audio（本地 Blob，可选）
                    ├── Notes 笔记（摘要层，与 Cue 原文层分离）
                    ├── Language 语言拆解（词汇 / 句式 / 纠错=听力陷阱）
                    └── Clip 片段标记（kind = stuck 卡点 | clip 素材） ──> Tag 标签
```

- **Cue**：句级单元（约 5–40 词），含 `start/end`、`text`（可纠错）、`raw`（ASR 原文）、`tr{zh,fr,en}`。
- **Part**：Lesson 内的主题片段；是笔记摘要、专题练习、进度统计的基本单元。
- **Clip**：时间轴上的一段 `[start, end]`；`kind=stuck` 进入训练队列，`kind=clip` 为带标签素材。
- 完整字段见附录 B。

## 7. 非功能需求

| 类别 | 需求 |
|---|---|
| **性能** | 首屏 < 2 s；2 小时课时（≈ 2,000 Cue）打开 < 1 s；播放/拖拽时 UI 保持 60 fps（当前句高亮绕过 VDOM）；搜索 < 300 ms |
| **延迟** | 源语言字幕 P50 < 1.5 s；译文 P50 < 2 s；点击跳转到出声 < 200 ms；变速即时。连续不停顿讲课时第一句字幕 ≤ 7 s（FR-1.15） |

| **插件延迟** | 字幕出现 → 译文：Google 免费翻译一般 < 0.5 s；AI（快速模型）约 1–2 s；命中"提前翻译"缓存为 0；未启用时对页面零开销（只监听消息） |
| **离线** | 库、Studio、训练、导入、离线摘要无网络可用；仅 Live 识别、云翻译、Claude 需联网 |

| **合规** | 首次开启录音必须确认"已获得授课教师/学校许可"；提供一键清除；不上传、不共享他人声音 |
| **准确性** | AI 输出必须带 `cue` 锚点且服务端校验索引；纠错项的 `wrong` 必须在原文真实出现（服务端校验，防幻觉）；译文条数与输入严格对齐 |

| **可用性** | 全键盘可操作 Studio/训练；颜色对比度满足 WCAG AA；动画尊重 `prefers-reduced-motion` |
| **可扩展** | ASR / 翻译 / LLM 均通过 Provider 接口接入，可替换；播放引擎可替换；UI 层与领域层解耦（便于迁移 React/插件） |
| **成本** | 一堂 90 分钟课的 AI 成本 ≤ 约 0.6 美元（笔记+语言拆解用 Opus 5.5、翻译用 Haiku 5.5 时；见 §9.4）。翻译若也用 Opus 5.5，单语言再增约 0.8 美元，应由用户显式选择 |
| **可靠性** | 所有写入先落 IndexedDB 再更新 UI；Live 期间每 30 秒落盘一次草稿，意外关闭可恢复 |
| **可观测** | 本地事件日志（匿名、可关闭），用于验证 §3.2 指标 |

### 9.1 总体架构

│ 自带密钥(localStorage) ─────────┼──直连/ /relay ─▶ 各家 LLM（在线版：密钥只在用户浏览器）
└────────────────────────────────┘              └───────────────────────────┘
        音频永不离开设备（默认）

Chrome 字幕翻译插件（独立安装，与上面互不依赖）
┌──────────────────────────────────────────────────────────────┐

部署形态：**在线版**（Cloudflare Workers：静态资源 + 一个很小的 `/relay`）、**本地版**（`npm start` 或一键脚本，密钥放服务端环境变量）、**插件**（开发者模式加载；zip 从 Web 应用设置页下载）。

### 9.2 语音识别（ASR）选型 —— **Claude 不处理音频，必须另选 ASR**

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| **浏览器 Web Speech API** | 零成本、零后端、en/fr/zh 均支持、interim 结果快 | 仅 Chrome/Edge/Safari；音频发往浏览器厂商云；无词级时间戳；无法吃标签页音频；会自动中断；术语弱 | **MVP 采用** |
| Deepgram（Nova 系列，流式 WebSocket） | 低延迟、词级时间戳、可加关键词提升（keyterm）、多语 | 需后端转发密钥；按分钟计费 | **V1 首选云 ASR** |
| Azure AI Speech | 自动语种识别、**短语表**（注入课程术语）成熟、企业合规好 | SDK 较重 | V1 备选（术语注入强） |
| Google Cloud STT（Chirp） | 多语好、与 Google 翻译同生态 | 流式接入复杂度中等 | 备选 |
| OpenAI 转写（gpt-4o-transcribe / whisper-1） | 文件转写质量高、带时间戳；适合**课后重转写** | 实时性依赖接口形态 | **课后"重转写+对齐"首选（V1）** |
| 本地 whisper.cpp / faster-whisper | 免费、离线、隐私最好 | 需本机算力/安装 | 高级用户选项（V1+） |

**插件第二阶段（无字幕视频，P2，未做）的音频识别评估**：

| 方案 | 说明 | 取舍 |
|---|---|---|
| `chrome.tabCapture` + offscreen document → 云 ASR | 捕获标签页音频（不经过麦克风、不被环境音干扰），16 kHz PCM 流式发给 Deepgram / Azure 等 | 质量与延迟最好；**要另一类密钥**（ASR 服务），有按分钟的成本 |
| Chrome 本机语音识别（Web Speech 的本机模型 / 可传入 MediaStreamTrack） | 免费、可离线 | 版本与语言包依赖强，**我没有验证过能否喂标签页音频**；en/fr/zh 本机模型覆盖需实测 |
| 麦克风拾取扬声器 | 最简单 | 受环境音影响，不推荐 |

在用户确认"无字幕视频"确有需求前不做（开放问题 6）。

**重要**：课后若拿到音频，可用 Whisper 类服务重转写获得**真实词级时间戳**，从而替代"估算时间轴+锚点校准"；这是 V1 最高性价比升级。

### 9.3 翻译选型：Google Translate vs Claude vs 其他

| 维度 | Google Cloud Translation（Basic v2 NMT） | Claude（Haiku 5.5 / Opus 5.5） | DeepL API | Chrome 内置 Translator API |
|---|---|---|---|---|
| 延迟（单句） | **~100–300 ms** | 约 0.5–2 s（Haiku）；Opus 更慢 | ~200–500 ms | 本地，~100 ms |
| 确定性/不幻觉 | **高**（逐句直译，不会"加戏"） | 中（需约束提示+对齐校验） | 高 | 高 |
| 对 ASR 噪声/口头禅的鲁棒性 | 差（"uh, uh, she, I need…"会直译） | **好**（可清理语气词、理解半句） | 中 | 差 |
| 术语一致性 | 需 v3 Glossary | **提示词注入课程术语表即可** | 有词表 | 无 |
| 语言覆盖 en/fr/zh | ✔ | ✔ | ✔（中文质量中上） | 依赖语言包 |
| 价格（量级） | ~$20 / 百万字符，每月前 50 万字符免费 | Haiku 5.5：$0.10 / $0.50 每百万 token；Opus 5.5：$4 / $20 | ~$25 / 百万字符（Free 档 50 万字符/月） | 免费 |
| 自建复杂度 | 低（REST） | 低（SDK） | 低 | 仅浏览器端 |

**成本测算**（一堂 90 分钟课 ≈ 13,000 词 ≈ 7.5 万字符 ≈ 1.8 万 token；单个目标语言）：

| 方案 | 估算 |
|---|---|
| Google NMT | 7.5 万字符 × $20/M ≈ **$1.5**（免费额度约覆盖每月 6 堂课·单语言） |
| Claude Haiku 5.5 | 输入 ≈ 1.9 万 + 输出 ≈ 3.5 万 token ≈ **$0.02** |
| Claude Opus 5.5 | 同上 ≈ **$0.8** + 思考 token |

**决策：Provider 链 + 分场景**

1. **课中实时字幕**：`translate` 接口按 `Google → Claude → 浏览器内置 → 不翻译` 顺序自动选择可用者。有 Google 密钥时用 Google（最低延迟、不幻觉）；仅有 Claude 密钥时用 Claude（推荐 `CLAUDE_MODEL_FAST=claude-haiku-5-5`，成本约为 Google 的 1/70）。
2. **课后"二次精翻"**（P1）：用 Claude + 课程术语表 + 前后文，对实时译文做替换，更适合沉淀为长期素材。
3. **翻译失败不阻塞**：译文是增强项，不是阻塞项。

**插件里的字幕翻译（与上面的课堂实时翻译是两条独立链路）**：

| 引擎 | 延迟 | 质量 | 成本/密钥 | 备注 |
|---|---|---|---|---|
| **Google 免费网页接口**（`translate_a/single?client=gtx`） | < 0.5 s | 够看；口语/俚语一般 | 免费，无需密钥 | **非官方接口**：可能被限流或改动；是插件的默认兜底 |
| **AI（用户的密钥，快速模型）** | 1–2 s | 最好：能保留语气、俚语、玩笑、称呼 | 按用量，字幕很短所以便宜 | 影视字幕专用提示词（`subtitleTask`），带前 3 句上下文；失败自动降级 |
| **Chrome 内置 Translator** | 本机 ~100 ms | 中 | 免费、离线 | 语言包必须已下载；只在其余都失败时作为降级，**不在后台触发下载** |

选择逻辑：`auto` = AI → Google 免费 →（Chrome 内置，语言包就绪时）→ 只显示原文。DOM 字幕没法提前翻译，所以 AI 引擎下译文会晚 1–2 s；视频字幕轨道整条载入时则**提前翻译未来 ~90 秒**，没有这个延迟。

> 说明：以上价格为公开价量级的估算，上线前以官方价目为准。代码默认 `CLAUDE_MODEL=claude-opus-5-5`；`CLAUDE_MODEL_FAST` 默认同主模型，建议用户按预算改为 Haiku 5.5。

### 9.4 Claude 的使用面与成本

| 任务 | 端点 | 输入 | 输出（结构化 JSON） | 推荐模型/effort | 单堂课成本（估） |
|---|---|---|---|---|---|
| 笔记归纳 + 主题分段 | `/api/ai/notes` | 全部 Cue（`idx｜text` 紧凑格式）≈ 1.9 万 token | Part 标题/摘要、要点、概念、公式、老师强调、待问（均带 `cue`） | Opus 5.5 · medium | ≈ $0.2 |
| 语言拆解 | `/api/ai/language` | 同上 + 课程术语表 | 纠错、词汇、句式、扩展 | Opus 5.5 · medium | ≈ $0.25 |
| 翻译（无 Google 时） | `/api/translate` | 批量句子 + 前 3 句上下文 | 对齐数组 | Haiku 5.5 · low（推荐） | ≈ $0.02 / 语言 |
| 插件字幕翻译 | 用户密钥直连（插件后台） | 每批 ≤ 8–12 句 + 前 3 句上下文 | 对齐数组 | 快速模型 · low | 一集 45 分钟约 600 句 ≈ 几美分 |

**关键工程约束**

- 使用官方 `@anthropic-ai/sdk`；长输出一律**流式 + `finalMessage()`**，避免超时。
- 使用 `output_config.format`（JSON Schema）获取严格结构化输出；`output_config.effort` 控制思考深度。
- Opus 5.5 思考不可关闭、forced `tool_choice` 不可用——本方案不依赖二者。
- 默认启用服务端 `fallbacks: "default"`（beta `server-side-fallback-2026-07-01`；Haiku 不支持则不带）；可用环境变量关闭。
- **必须处理 `stop_reason: "refusal"`**：生命科学类课程（如 *Bioinformatics & Omics*）可能触发 `bio` 安全分类器的误判；产品降级为离线版并明示原因。
- 服务端校验：`cue` 索引越界裁剪；纠错项 `wrong` 必须原文真实出现；译文数量必须与输入一致，否则重试/降级。

| 成本失控 | 低 | 中 | 默认单次调用；Haiku 档位；用量提示；本地缓存结果避免重复生成 |

| **插件：站点改版导致字幕读不到** | 高 | 中 | 站点适配只是"第一层"；始终提供**手动选取**与**标准字幕轨道**两条不依赖站点结构的路径；状态里明示当前字幕来源 |

| **版权 / 站点条款** | 中 | 中 | 只读取页面里已经显示的字幕文字用于个人学习翻译；不下载/转存视频或字幕文件，不分发。v0.2 起会在**本机**保存看过的字幕文字（转录、翻译记忆），不上传、不共享；设置页可一键清除；导出只包含用户自己收藏的单词/句子 |

| 悬浮字幕/PiP 浏览器差异 | 中 | 低 | 能力探测，不支持时隐藏"弹出到桌面"并说明；浏览器窗口无法真正透明（只提供深浅主题） |
| 多服务商密钥（除 Anthropic 外）未经真实验证 | 高 | 中 | 界面标"实验性"；模型名不写死，探测 `/models` 再挑；`/relay` 主机白名单；测试用模拟服务覆盖逻辑，上线后以用户反馈修正 |

## 12. 开放问题

| 4 | `super vector` | support vector | B×1 | 弱读 |
| 5 | `Ginny's score` / `genius (purity) score` / `juniscore` / `injury scope` / `charity score` / `insurance score` / `the genie entering the school` | Gini score / Gini impurity | A×≥7 | 外来词读音（**同一个词至少 7 种误听变体**） |
| 6 | `decision speed, which speaks attribute` | decision split, which tests an attribute | A×1 | 近音 |
| 7 | `biased variance trade` | bias–variance trade-off | A×1 | 漏读 |
| 8 | `a kernel fashion` | a kernel function | B×1 | 近音 |
| 9 | `entropy and risk specification error` | entropy and misclassification error | A×1 | 近音/切词 |
| 10 | `forces for the … bagging` | forests … bagging | A×1 | 近音 |
| 11 | `randomness on the teachers` | randomness on the features | A×1 | 近音 |
| 12 | `a detective reverse tree` | a reversed (inverted) tree | A×1 | 推测 |

> 样本规模约 2.9 万词，上述可辨识的**术语级**错误约每 2,500 词一处，但都集中在承载课程含义的核心概念上。

## 附录 C · 术语表

| 术语 | 含义 |
|---|---|
| Cue | 句级听力单元（字幕条） |
| Part | 主题片段（3–8 分钟） |
| 卡点 / Stuck | 用户标记为"没听懂"的时间段 |
| 盲听 | 隐藏文字，仅凭听力理解 |
| 听力陷阱 | ASR 曾误识、学生可能同样误听的术语 |
| 锚点 | 用户确认的"此句 ↔ 此时间"对应，用于校准估算时间轴 |
| 稳定前缀提交 | 连续讲话时，把识别假设里已经稳定的前半部分提前提交成一句（FR-1.15） |
| TextTrack | 浏览器标准的视频字幕轨道（`<track>` / WebVTT）；插件的字幕来源之一 |
| 悬浮层 / Overlay | 插件显示在视频画面上的译文块（Shadow DOM） |
| 翻译记忆 / TM | 翻译过的句子永久缓存（原文 → 译文），再次遇到直接复用 |
| 转录 | 一个视频里识别到的全部字幕句子（原文 + 译文 + 时间），保存在本机 |
